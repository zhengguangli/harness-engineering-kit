## 自动化检查脚本 Bug 分析

在本次批量评估中，使用项目目录下的 `automated-check-script.sh` 运行自动化检查时发现以下脚本自身问题：

### Bug 1: check_common_edge_cases() 路径错误（影响 13/13 skill）

**问题**: `check_common_edge_cases` 函数中：
```bash
skill_dir=$(dirname "$(dirname "$file")")  # 当前行为：./skills
```
实际需要：
```bash
skill_dir=$(dirname "$file")  # 应改为：./skills/harness-xxx
```

**影响**: 所有 13 个 skill 的 `common-edge-cases.md` 和 `automated-check-script.sh` 存在性检查均为误报警告。实际所有 13 个 skill 的这两个文件均存在。

**严重程度**: LOW（不影响实际使用，仅影响脚本输出结果）

### Bug 2: agent-prompt 标题语言不一致（影响 13/13 skill）

**问题**: 自动化检查脚本搜索 `^##\s+Agent Prompt` 英文标题，但所有 SKILL.md 文件使用 `## Agent 提示词` 中文标题。

**影响**: 所有 13 个 skill 的 `agent-prompt` 检查均为误报 FAIL。

**严重程度**: LOW（语言翻译后的遗留问题，自动化检查脚本需要更新搜索模式）

### Bug 3: 加权评分脚本 context trim 问题（影响 1 skill）

**问题**: `check_fm_context()` 在 `context值为 ' fork'` 中检测到 `context: fork` 值前导空格（实际为正常空格），误报警告。

**影响**: skill-quality-assessor 在自动化友好度维度的扣分。

**严重程度**: LOW（自第 12 次评估指出以来已持续 3 个评估周期未修复）
